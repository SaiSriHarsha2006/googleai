How Do Transformers Learn Code?

Modern AI code assistants (like Gemini, GitHub Copilot, and our local models) are based on the **Transformer Decoder** architecture. They are trained to solve a single, simple objective: predict the next token given a sequence of preceding tokens.

1. Tokenization

Computers don't understand words or characters directly. First, we break text into numbers. Our scratch model uses character tokenization: every character (like d, e, f, ) gets mapped to a specific index. Pre-trained models use subword tokenization to compress multiple letters into single tokens (e.g. return becomes one token).

2. Attention Mechanics

The magic is in Self-Attention. It allows the model to look back at earlier parts of the code to calculate relationships. For example, when it sees a closing bracket ), self-attention helps it align back to the exact opening parenthesis ( it corresponds to, even if they are lines apart.

3. Autoregressive Generation

When generating code, the model predicts the probability distribution of the next character. We sample a character from that distribution, append it to the prompt, and feed the entire sequence back to the model to predict the next one. This loop repeats character-by-character or token-by-token.

4. Temperature & Sampling

Temperature controls the creativity. A high temperature (e.g. 1.2) flattens the probability distribution, making the model more creative but highly prone to syntax mistakes. A low temperature (e.g. 0.2) makes it choose only the absolute most likely tokens, leading to repetitive or rigid code.
